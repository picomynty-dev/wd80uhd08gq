# My Fit Plan 3.1.2

Aplicación web progresiva de entrenamiento con rutinas recomendadas, plantillas, rutinas propias, registro serie por serie, progresión, biblioteca de ejercicios y personalización visual.

## Novedad de esta versión

Los días del plan y los ejercicios de una sesión se pueden desplegar y recoger. En una sesión solo queda abierto el ejercicio que estás realizando, reduciendo mucho el desplazamiento vertical en el móvil.

## Publicación

Sube el contenido del proyecto a la raíz de tu repositorio de GitHub Pages. Las carpetas `js`, `assets` e `icons` deben conservar su estructura.
