# My Fit Plan 2.2

Aplicación web instalable para planificar y registrar entrenamientos desde móvil.

## Novedades

- Interfaz más compacta y cómoda en iPhone.
- Filas de series rediseñadas con mejor contraste al completarlas.
- Calendario mensual, semana y marcas recientes en Inicio.
- Búsqueda avanzada tolerante a errores, palabras múltiples y sinónimos.
- Filtros por músculo, material y nivel.
- Biblioteca ampliada a 283 ejercicios.
- Ilustración vectorial de movimiento y mapa muscular para cada ejercicio.
- Carga progresiva de resultados para mantener la aplicación rápida.
- Migración automática de los datos guardados en la versión 2.1.

## Publicar en GitHub Pages

Sube todos los archivos y carpetas de este proyecto a la raíz del repositorio. Deben verse `index.html`, `styles.css`, `service-worker.js`, `icons/` y `js/` directamente en la página principal.

## Privacidad

Los datos continúan guardándose únicamente en `localStorage` en el dispositivo. No hay cuentas ni servidor.
