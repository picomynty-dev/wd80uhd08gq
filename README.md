# My Fit Plan v3.3 · Progreso físico privado

## Funciones nuevas
- Fotografías frontal, lateral y posterior.
- Compresión automática para ahorrar espacio.
- Almacenamiento privado mediante IndexedDB.
- Peso y seis medidas corporales por fecha.
- Gráfico de evolución de medidas.
- Comparación lado a lado.
- Deslizador antes/después.
- Exportación de las fotografías de cada revisión.
- Eliminación completa de fotografías y medidas.
- Bloqueo opcional con PIN dentro de la aplicación.

Las fotografías no se envían a ningún servidor y no se incluyen en la copia
JSON habitual. Se recomienda exportar las imágenes importantes antes de borrar
los datos del navegador o cambiar de dispositivo.
