# My Fit Plan v3.4A · Entrenador inteligente

## Funciones principales
- Motor de progresión por ejercicio.
- Detección de estancamientos suaves.
- Detección de dos sesiones por debajo del rango.
- Recomendación de subir, mantener o reducir carga.
- Análisis de carga, repeticiones, volumen, series y RIR.
- Nueva tarjeta profesional del entrenador en Inicio.
- Panel completo para la próxima sesión.
- Resumen semanal con adherencia, mejoras y récords.
- Lectura automática al finalizar un entrenamiento.

El análisis funciona localmente mediante reglas transparentes. No necesita una
API de inteligencia artificial y no envía el historial fuera del dispositivo.
