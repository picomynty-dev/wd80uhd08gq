# My Fit Plan v3.2.3A · Real Motion

Versión piloto centrada en elevar la calidad visual de la biblioteca.

## Cinco ejercicios Real Motion
- Press banca con barra
- Jalón al pecho
- Prensa de piernas
- Curl de bíceps
- Bird dog

Los cinco utilizan un modelo anatómico sombreado con músculos principales
y secundarios integrados en el propio movimiento. También sustituyen la
antigua tarjeta de palitos por una miniatura del render real.

Los demás ejercicios mantienen temporalmente la demostración anterior hasta
validar este nuevo estándar visual.
